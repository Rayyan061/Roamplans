RoamPlans Travel Technology image slots

Add each post's images to this folder using the exact filenames referenced in
the HTML. Recommended format: WebP, 1600 x 1000 pixels (16:10 landscape).

Each article supports:
- {post-slug}-comparison.webp
- {post-slug}-section-guide.webp

The comparison image appears after the first comparison table. The section
guide image appears beneath a main content heading. No image is placed in the
intro or directly before Key Takeaways.

If an image has not been added yet, its figure is automatically hidden and no
broken-image icon is displayed.
